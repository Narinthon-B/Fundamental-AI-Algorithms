
# 8-Puzzle
## Problem Description
8-Puzzle ประกอบด้วยตารางขนาด 3 x 3 ที่มีแผนป้ายตัวเลข 1 ถึง 8 และช่องว่าง 1 ช่อง (แทนด้วยเลข 0)

**เป้าหมาย** คือ การเลื่อนแผ่นป้ายที่อยู่ติดกับช่องว่างเพื่อจัดเรียงตัวเลขให้ตรงกับสถานะเป้าหมาย (Goal State) ที่กำหนดไว้ ในมุมมองของ AI ปัญหานี้ถูกจำลองเป็น State-Space Search ที่มีความซับซ้อนสูง เนื่องจากจำนวนสถานะที่เป็นไปได้ทั้งหมดมีถึง 9! หรือ 362,880 สถานะ

## Algorithm: Breadth-First Search (BFS)

ในโปรเจกต์นี้เลือกใช้ **BFS** เนื่องจากมีคุณสมบัติที่สำคัญคือ:

-   **Optimality:** รับประกันว่าจะเจอคำตอบที่ใช้จำนวนการเดิน (Moves) น้อยที่สุดเสมอ หากนํ้าหนักของทุกกิ่งเท่ากัน
    
-   **Completeness:** ถ้าปัญหามีทางแก้ BFS จะหาคำตอบเจอแน่นอน

### Technical Implementation

-   **Data Structure:** ใช้ `collections.deque` สำหรับทำ Queue เพื่อประสิทธิภาพในการ `popleft()` ที่รวดเร็ว
    
-   **State Tracking:** ใช้ `visited` dictionary เพื่อเก็บสถานะที่เคยผ่านมาแล้ว ป้องกันการเกิด Infinite Loop และใช้สำหรับเก็บ State ว่า State นี้มาจากไหน
    
-   **Movement Logic:** ใช้การคำนวณ `divmod(index, 3)` เพื่อแปลงตำแหน่งจาก List 1 มิติ ให้เป็นพิกัด $(row, col)$ ใน 2 มิติ เพื่อตรวจสอบเงื่อนไขการเลื่อนที่ถูกต้อง (Up, Down, Left, Right)
