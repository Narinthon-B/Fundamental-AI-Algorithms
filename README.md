# Fundamental AI Algorithms Implementation
Repository นี้รวบรวมการ Implement อัลกอริทึมพื้นฐานทางด้าน **Artificial Intelligence** โดยมุ่งเน้นไปที่ทฤษฎีการแก้ปัญหาด้วย Search Algorithms, Optimization และ Game Theory เพื่อสร้างรากฐานที่แข็งแกร่งสำหรับการต่อยอดในสายงาน Data และ AI

## Project Overview

โปรเจกต์นี้เป็นการนำทฤษฎี AI ในบทเรียนมาเปลี่ยนเป็น Code ด้วยภาษา Python เพื่อจำลองการแก้ปัญหาในรูปแบบต่างๆ ตั้งแต่ State Space Search ไปจนถึงแนวคิดด้าน Optimization

### Contents & Algorithms

ใน Repository นี้ประกอบไปด้วยหัวข้อที่น่าสนใจดังนี้:

-   **[8-Puzzle](https://www.google.com/search?q=./8-Puzzle):** การแก้ปัญหาตัวต่อ 8 ชิ้น โดยใช้เทคนิค Search และ Heuristics เพื่อหาเส้นทางที่สั้นที่สุดไปยังเป้าหมาย
    
-   **[Searching Algorithms](https://www.google.com/search?q=./Searching-algorithms):** การรวบรวมและเปรียบเทียบประสิทธิภาพของอัลกอริทึม BFS และ DFS ในการค้นหา
    
-   **[Tower of Hanoi](https://www.google.com/search?q=./Tower-of-Hanoi):** การแก้ปัญหาโดยใช้แนวคิด **Recursion** และการบริหารจัดการ State Space
    
-   **[Travelling Salesman (TSP)](https://www.google.com/search?q=./Travelling-Salesman):** การแก้ปัญหาการเลือกเส้นทางที่เหมาะสมที่สุด (Optimization) เพื่อหาเส้นทางที่สั้นที่สุดในการเดินทางผ่านจุดต่างๆ
    
-   **[XO-game (Tic-Tac-Toe)](https://www.google.com/search?q=./XO-game):** การสร้าง AI สำหรับเล่นเกมโดยใช้แนวคิด **Minimax Algorithm**
