# Travelling Salesman Problem (TSP)

## Problem Description

พนักงานขายต้องเดินทางไปยังเมืองต่างๆ ทั้งหมด $n$ เมือง โดยมีเงื่อนไขว่า:

1.  ต้องผ่านทุกเมือง เมืองละ 1 ครั้งเท่านั้น
    
2.  ต้องเดินทางกลับมายังเมืองเริ่มต้น (Starting City)
    
3.  ต้องหาเส้นทางที่มี **ค่าน้ำหนักรวม (Total Cost)** น้อยที่สุด

เมื่อนำอัลกอริทึม **Breadth First Search (BFS)** มาใช้แก้ปัญหา TSP กระบวนการทำงานจะเปลี่ยนจากการค้นหาในกราฟแผนที่เมืองโดยตรง เป็นการค้นหาใน State Space Tree แทน โดยกำหนดให้เมืองเริ่มต้นเป็น Root Node และทำการขยายโหนดไปยังเมืองที่ยังไม่เคยถูกเยี่ยมชมในระดับถัดไป การทำงานของ BFS ในบริบทนี้คือการสร้างเส้นทางที่เป็นไปได้ทั้งหมดพร้อมๆ กัน โดยในแต่ละระดับของต้นไม้จะหมายถึงจำนวนเมืองที่ได้เดินทางไปแล้ว เมื่อ BFS ทำงานไปจนถึงระดับความลึกที่ N (ครบทุกเมือง) เราจะได้เส้นทางที่สมบูรณ์ทั้งหมด จากนั้นจึงนำเส้นทางเหล่านี้มาเปรียบเทียบระยะทางรวมเพื่อหาเส้นทางที่สั้นที่สุด 

แม้ว่า BFS จะรับประกันได้ว่าเราจะเจอคำตอบที่ดีที่สุดแน่นอน แต่ในทางปฏิบัติ BFS ไม่เหมาะกับ TSP ที่มีเมืองจำนวนมาก เพราะต้องใช้หน่วยความจำมหาศาลในการเก็บทุกเส้นทางที่กำลังสร้างพร้อมกัน

## Example Output
จากรูป จะแสดงการสํารวจเส้นทางไปทีละระดับ จนครบทุกเมือง จากนั้นจะเปรียบเทียบหาเส้นทางที่ Minimum Cost ที่สุด
